Catalogo API


L'applicazione dispone di servizi API in formato REST che permettono ad altre applicazioni o script di accedere ai valori di particolato registrati dalle centraline Luftdaten. Il servizio permette l'accesso ai valori di particolato, sia realtime sia storici, per una area di interesse desiderata, grazie ad un paradigma di URL illustrato di seguito. Eventuali errori nell'utilizzo delle API vengono segnalati attraverso codici di risposta HTTP. Per tutte le richieste e le risposte dall'API viene utilizzato il formato JSON.

Di seguito è mostrato il paradigma delle API e delle relative informazioni associate.

Elementi al dettaglio


Queste API mostrano l'insieme dei dati associati a una specifica area di interesse o a una specifica serie storica definita da un set di parametri.
Ogni area di interesse è identificata da un corrispondente ID.
Ogni set di parametri che definisce una serie storica è identificata da un corrispondente ID.

È possibile reperire i dati associati ad una specifica area di interesse o ad uno specifico set di parametri inserendo il suo ID nell'endpoint dell'API, avendo cura di inserirlo nella posizione corretta.

Il catalogo delle aree di interesse con relativo ID è consultabile a questo link.

Il catalogo dei set di parametri che definiscono le serie storiche con relativo ID è consultabile a questo link.
